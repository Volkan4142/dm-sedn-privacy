Privacy Policy - dm sedn

This application ("dm sedn") is used to manage and respond to Instagram Direct Messages and manage Instagram content on behalf of connected business accounts using the official Meta (Facebook) Graph API.

Data We Collect

How We Use Data

Data is processed solely for the purpose of reading, responding to Instagram Direct Messages, and managing Instagram business content.

Data Storage

No personal data is permanently stored on external servers. Data is accessed temporarily via the Meta Graph API for operational purposes only.

Data Sharing

We do not sell, trade, rent, or share user data with third parties.

Data Security

All data access is performed via secure HTTPS connections using official Meta APIs.
